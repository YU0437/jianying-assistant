# Jianying Assistant

[简体中文](README.md) ｜ **English**

A pre-compose export helper for Jianying Pro.

![UI preview](docs/ui-preview-static.png)

## Effects

- Stickers, transitions and similar effects require no membership.
- For operations that require membership, use **Pre-compose export** (slower).
- Other UI text is kept to essential prompts only.

## Usage

1. Open Jianying Pro, enter a draft and select the content to process.
2. Click the floating ball and follow the prompts to pre-compose, drag in and export.
3. After exporting, click the floating ball to restore the draft.

## Installation

1. Download `剪映助手-Setup-x.y.z.exe` from [Releases](../../releases).
2. Run the installer, then launch Jianying Assistant.

See [Installation guide](docs/INSTALL.en.md) for details.

Supports Windows 10 / 11 x64. Jianying must have been opened at least once.

## Notes

- When Jianying closes, the assistant keeps waiting in the background; the ball reappears when Jianying is opened again.
- The workflow restarts Jianying and clears the current timeline. The assistant backs up the draft first and can restore it after export.
- It only simulates keyboard/mouse input and moves windows; it does not modify video files.
- Use only drafts you own the rights to, and keep your own backup.
- Actual results depend on the current Jianying version and account status.
- This project is not affiliated with Jianying.
