# 剪映助手

**简体中文** ｜ [English](README.en.md)

用于剪映专业版的预合成导出辅助工具。

![界面预览](docs/ui-preview-static.png)

## 效果

- 贴纸、转场等效果免会员。
- 需要会员的操作可选择「预合成导出」，速度较慢。
- 其他界面只显示必要提示。

## 使用

1. 打开剪映专业版，进入草稿并选中要处理的内容。
2. 点击悬浮球，按提示完成预合成、拖入和导出。
3. 导出完成后点击悬浮球，还原草稿。

## 安装

1. 下载 [最新版本](../../releases) 中的 `剪映助手-Setup-x.y.z.exe`。
2. 双击安装，完成后启动剪映助手。

详细步骤见 [安装教程](docs/安装教程.md)。

支持 Windows 10 / 11 x64；剪映需至少打开过一次。

## 注意

- 关闭剪映后助手会继续在后台等待，重新打开剪映时小球自动出现。
- 流程会重启剪映并清空当前时间线；助手会先备份草稿，导出后可还原。
- 只模拟键鼠、移动窗口，不修改视频文件。
- 请仅处理自己拥有版权的草稿，并提前备份。
- 实际效果以当前剪映版本和账号状态为准。
- 本项目与剪映官方无关联。
